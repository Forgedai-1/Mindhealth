## Reporting a Vulnerability

Please report any security vulnerabilities responsibly. If you discover a security issue, please contact the maintainers directly. Do not open public issues for sensitive security vulnerabilities.

We take all security vulnerabilities seriously and will respond as quickly as possible to evaluate and address reported issues.
